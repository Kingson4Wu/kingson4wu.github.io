# 《AI 失控风险》SVG 视觉化设计

日期：2026-09-25

## 目标

为 `content/zh/posts/20260924-ai-loss-of-control.md` 增加五张解释型 SVG，降低长篇纯文字的阅读压力，同时保持正文的事实边界、个人判断和可检索文本。

图像只用于解释层级、流程、反馈循环和概念边界，不替代无法脱离上下文理解的论述。

## 视觉方向

- 暖纸张背景：`#fbf7ef`
- 深蓝主色：`#173f63`
- 卡片底色：`#fffdf8`
- 暗红：`#9a3b2f`，表示风险、越界和未证实状态
- 暗绿：`#1f7a57`，表示现状、稳定路径和已建立环节
- 蓝灰：`#89a6bd`、`#6f7f8d`，用于辅助线和次要说明
- 标题使用 `Georgia, 'Times New Roman', serif`
- 正文标签使用适合中文显示的系统字体栈
- 不使用渐变、阴影、发光、装饰性图标或高饱和颜色

### 1. `risk-escalation-threshold.svg`

放在“先把‘人类灭绝’的门槛说清楚”小节。

内容从左到右展示：

`局部越权或失效 → 系统性事故 → 长期脱离控制 → 人类灭绝`

图中明确表达越往右门槛越高、现有证据越少，并在下方列出主动失控走向灭绝需要同时满足的能力、行为倾向、部署环境和持续阻止恢复等条件。

### 2. `knowledge-discovery-loop.svg`

放在“‘不知道’其实有不同层次”小节，替换现有知识发现 ASCII 流程。

主体为闭环：

`已有知识 → 提出假设 → 设计实验 → 获得新数据 → 分析验证 → 形成新知识 → 新一轮假设`

旁边以三个简短层级区分“训练数据无答案”“人类暂时无答案”“尚未形成问题或概念”。图中保留“新结果不等于正确，需要独立验证”的限制。

### 3. `capability-permission-paths.svg`

放在“AI 获得权限的两条路径”小节之前或两条路径讲完之后。

上半部分展示高风险组合：能力、自主性、现实权限和不可预测性。下半部分展示权限扩张的两条路径：人类主动授权，以及通过漏洞或配置缺口越权。两条路径汇入“实际行动空间扩大”。

### 4. `competition-feedback-loops.svg`

放在“两条路径会同时发生”小节，替换现有双循环 ASCII 图。

图中包含两个相互增强的循环：

- 能力提高 → 授予更多权限 → 完成更多任务 → 依赖增加；
- 能力提高 → 发现更多攻击路径 → 突破安全边界 → 行动空间增加。

外层增加竞争压力，说明局部理性的决策如何累积成整体风险。图中不暗示所有 Agent 都会主动寻找攻击路径。

### 5. `recursive-improvement-boundary.svg`

放在“关于‘递归自我改进’的边界”小节，替换现有 ASCII 流程。

左右对比：

- 当前：AI 参与研发，人类仍控制训练、评估和发布；
- 未来假设：后继系统持续加速下一轮研发，完整闭环尚未被证明实现。

底部单独强调：递归自我改进、自主部署和失去控制是三个不同概念，前者即使实现也不必然导致后两者。

## 正文修改原则

- 使用 `<figure>`、`<img>` 和 `<figcaption>` 嵌入图片。
- 每张图提供准确的 `alt`、SVG `<title>` 和 `<desc>`。
- 删除被完整替代的 ASCII 流程，避免图文重复。
- 保留解释条件、事实限定和个人观点的段落。
- 不改变标题、frontmatter、参考资料和文章三部分结构。
- 不新增未经事实核查的案例或概率数字。

## 响应式与可读性

- SVG 使用固定 `viewBox`，不依赖固定显示宽度。
- 桌面端按文章内容宽度完整展示。
- 移动端缩放后，最小文字仍能辨认；必要时采用纵向或两行布局，避免将五到七个节点硬塞在同一横排。
- 连接线不得穿过文字，标签不得压住边框或箭头。
- 颜色之外必须同时依靠文字、线型或位置表达含义。

## 验证

1. 运行 `npm run check`。
2. 运行 `npm run build`。
3. 启动本地预览。
4. 分别在桌面宽度和移动端宽度截图。
5. 检查文字重叠、缩放可读性、图注、资源路径和正文重复。
6. 运行 `git diff --check`。

## 完成标准

- 五张 SVG 均位于文章专属资产目录。
- 五张图使用统一视觉语言，但布局不机械重复。
- 图像对应的结构化内容比纯文字更容易理解。
- 正文关键判断没有被图片吞掉或改变。
- 桌面端和移动端均无文字重叠、裁切或明显失衡。
- 内容检查、构建和差异检查全部通过。
